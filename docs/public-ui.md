# 官网前台基础组件规范

## 组件复用

| 场景 | 组件或基础样式 | 页面提供的内容 |
| --- | --- | --- |
| 地区、目录、对比维度等直接选择 | `PublicSelect` | `v-model`、`options`、标签和原生事件 |
| 需要搜索的单选列表 | `PublicSearchSelect` | `v-model`、`options`、标签、搜索提示、加载或错误状态 |
| 输入框和文本域 | `PublicFormField` 与 `.public-control` | 字段标签、提示或校验错误。输入控件通过 slot 绑定 `control` 属性 |
| 独立操作按钮和跳转链接 | `.public-button` | 文案与操作。主操作可加 `.public-button--dark` 或 `.public-button--gold` |
| 搜索面板和咨询弹窗 | `PublicDialog` | 标题、触发器和内容。有 `anchor` 时桌面定位到触发器，手机从底部打开 |

两类下拉的选项都用 `{ value, label }`，`value` 保持原有的字符串或数字类型。业务请求、筛选字段和表单校验由页面维护。普通状态使用 1px 边框，表单控件聚焦或展开时沿原边向内加粗。错误态保留红色边框和字段说明。

## 交互和过渡

| 交互 | 时长 | 过渡 |
| --- | --- | --- |
| 聚焦、按下、选中、校验状态 | 即时 | 状态立即显示 |
| 悬停 | 150ms | 颜色、边框或阴影 |
| 桌面自定义下拉、浮层 | 进入 200ms，退出 150ms | 淡入淡出与小幅位移 |
| 移动弹层、导航侧滑 | 进入 250ms，退出 200ms | 面板沿打开方向运动，遮罩同步 |
| FAQ、项目类型目录和移动导航子菜单 | 200ms | 内容展开与箭头转动同步 |
| 前台页面切换 | 150ms | 新页面淡入，筛选和分页更新局部 |

沿用 `variables.css` 中的前台时长变量。进入用 `ease-out`，退出用 `ease-in`。原生选项菜单沿用浏览器交互。系统开启减少动态效果时，显示和关闭仍可直接完成，键盘焦点可见并能恢复到入口。

弹层背景滚动锁由公开布局处理，主页面开关前后保留相同的滚动条空间。验收时检查鼠标和键盘、固定页头、移动底栏，以及快速开关和减少动态效果模式。
